# Сайт Александра — ведущего и организатора событий

Готовый адаптивный сайт на HTML, CSS и JavaScript. **Без сборки, npm, платных библиотек и подключения внешних шрифтов.**

## Запуск

1. Распакуйте ZIP.
2. Откройте `index.html` двойным нажатием. Сайт работает локально.
3. Для размещения загрузите **все файлы и папку `assets`** на любой статический хостинг — GitHub Pages, Netlify, Cloudflare Pages и т.д.

## ВАЖНО: включить приём заявок

У нас пока нет подтверждённых контактов Александра, поэтому сайт **не отправляет заявки автоматически**. В текущем варианте посетитель может подготовить и скопировать текст заявки. Это сделано намеренно: никто не должен думать, что заявка уже ушла, если адрес получателя не известен.

Перед публикацией откройте `config.js` и укажите **хотя бы один** рабочий контакт:

```js
window.SITE_CONFIG = {
  telegram: "username",      // ник Александра без @
  whatsapp: "375291234567",  // пример формата, НЕ реальный номер
  email: "hello@example.com", // пример формата, НЕ реальная почта
  youtube: "https://www.youtube.com/@aktivacia"
};
```

После заполнения посетители смогут перейти в WhatsApp с готовым сообщением, открыть почтовое приложение с заполненным письмом или открыть Telegram Александра (сообщение нужно будет вставить из буфера обмена). **Серверных отправок и сбора личных данных на сайте нет.** Для автоматической отправки и CRM понадобится подключить отдельный сервис или backend.

## Что на сайте

- Первый экран с подготовленным изображением Александра и сценическим эффектом.
- Разделы: ведущий, организация под ключ, артисты и шоу-программы, концерты и гастроли.
- Интерактивный процесс подготовки мероприятия.
- Блок об Александре с оригинальной фотографией.
- FAQ и форма краткого брифа.
- Анимации появления блоков, эффект движения в hero, подсветка карточек, мобильное меню, индикатор прокрутки.
- Отключение сложных анимаций для пользователей с `prefers-reduced-motion`.

## Что стоит заменить перед полноценной публикацией

- Проверить тексты и перечень услуг с Александром, особенно работу с артистами и крупными концертами.
- Указать контакты в `config.js`.
- При необходимости добавить реальное портфолио: афиши, фото с мероприятий, видео, подтверждённые отзывы. **Фальшивых кейсов и отзывов в шаблоне нет.**
- При использовании формы с последующей автоматической отправкой уточнить требования к обработке персональных данных и добавить соответствующее уведомление.
- После появления домена обновить URL для OG-превью на абсолютный адрес.

## Файлы

- `index.html` — структура и тексты.
- `styles.css` — визуальное оформление и адаптивная верстка.
- `script.js` — анимации и интерактив.
- `config.js` — контакты и YouTube.
- `assets/` — оптимизированные изображения и иконка.

Все изображения входят в архив; внешние ресурсы не требуются. Для работы на хостинге не требуется серверное окружение.
